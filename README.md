# Демонстрационный проект

Демонстрация архитектурных подходов и паттернов программирования. Приложение построено так, чтобы
быть легко масштабируемым и поддерживаемым.

## 🚀 Запуск

### Через Docker (рекомендуется для проверки)

```bash
docker compose up --build -d   # http://localhost:3000
```

### Через консоль

```bash
npm install
npm run dev   # http://localhost:3000
```

## 🎯 Требования к проекту (функционал)

1. Загружает с сервера JSON-файл с данными
2. Показывает прогресс загрузки в процентах
3. Есть кнопка отмены загрузки
4. Отображает данные в виде таблицы с виртуализацией (1000+ строк)
5. Реализован поиск по таблице: есть input, в котором пишем текст поиска; после окончания ввода
   начинается поиск (без кнопки Найти).
6. В найденных строках цветом выделяется поисковый запрос

## 📋 Реализация

1. Vite + TypeScript + React + ESLint
2. Prettier с совместимостью в ESLint
3. Таблица — TanStack Table
4. Виртуализация — TanStack Virtual
5. Input поиска — нативные элементы без UI библиотек
6. Архитектура — Feature-Sliced Design
7. Код разделён на компоненты и типизирован
8. Валидация — Zod
9. CSS-переменные для темизации (одна тема)
10. Минималистичное, но стильное оформление
11. API — https://jsonplaceholder.typicode.com/photos (5000 записей); выводятся id, title и миниатюра;
    по клику на миниатюру в новой вкладке открывается оригинал
12. Перехват ошибок API и повторная загрузка
13. Unit-тесты
14. Husky, lint-staged и пре-хуки
15. Docker Compose для демонстрации работы в контейнере (облегчённая сборка + nginx)
16. ADR-файлы для каждого архитектурного решения и зависимости — в `adr/`
17. README с инструкцией запуска

## ⚙️ Особенности

- По умолчанию загрузка начинается через кнопку. Автозагрузку можно включить переменной окружения
  `VITE_PHOTOS_AUTOLOAD=on`.
- Демонстрационная возможность задержки между запросами для тестирования отмены: переменная
  `VITE_API_ARTIFICIAL_DELAY_MS` (по умолчанию 300 мс, `0` — выключить).

## 🔧 Настройки окружения

Скопируйте `.env.example` в `.env` и переопределите параметры. Основные переменные:

- `VITE_API_URL` — URL API (по умолчанию JSONPlaceholder)
- `VITE_API_RETRIES` — число повторных попыток (по умолчанию 3)
- `VITE_API_RETRY_DELAY` — задержка между повторами, мс (по умолчанию 1000)
- `VITE_API_TIMEOUT_MS` — таймаут запроса, мс
- `VITE_API_PAGE_SIZE` — размер страницы (по умолчанию 500)
- `VITE_API_MAX_CONCURRENCY` — параллелизм загрузки страниц (по умолчанию 3)
- `VITE_API_TOTAL_PHOTOS` — fallback общего числа записей
- `VITE_PHOTOS_AUTOLOAD` — автозагрузка при открытии (`on`/`off`)
- `VITE_API_ARTIFICIAL_DELAY_MS` — искусственная задержка запросов, мс (по умолчанию 300)
